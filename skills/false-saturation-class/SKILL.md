# False-Saturation Class

A closure label on the coarse or naive channel is false when the finer
channel, already inside the same likelihood, stays open.

## Kill

If the finer channel is also closed under the source's own definition,
the closure was true. FSC does not fire. If the two channels are not the
same samples, FSC does not fire. If nobody reported closure, FSC does not
fire (the honest split belongs to RGC or to nobody).

## Do not re-issue

RGC, RSC, DPC, PDC, FPC, ANC, TPC, Tettelin open/closed as a finding,
PhyloThin as a method, Prasoodanan's widening-gap sentence.

reversal the published rectangle does not contain. From RSC-2026-10-11.
